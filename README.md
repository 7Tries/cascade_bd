# 🛡️ CASCADE GUARD: Система каскадного удаления и целостности БД

**CascadeGuard** — полнофункциональная высоконадежная система для каскадного удаления данных с математической гарантией сохранения **физической** и **логической** целостности реляционной базы данных.

Интерфейс приложения выполнен в **премиальном бруталистском редакционном стиле** (глубокий черный фон, крупная акцидентная типографика Oswald / Bebas Neue, характерные овальные капсульные кнопки с желтыми акцентами) с **плавным эффектом параллакса и свайп-жестами**.

## 🏛️ Архитектура сохранения целостности

### 1. Физическая целостность (Physical Referential Integrity)
- **Engine-Level Enforcement**: база работает в режиме `PRAGMA foreign_keys = ON;`, `journal_mode = WAL;`, `synchronous = NORMAL;`.
- **Топологический порядок «Листья-Вперёд» (Leaves-First Order)**: алгоритм Кана выстраивает строгую иерархию удаления снизу вверх (дочерние записи всегда удаляются раньше родительских).
- **2-Фазовое расцепление циклов (Cycle De-Coupling)**: циклические и self-referential внешние ключи (`employees.manager_id`, `projects.lead_id`, `tasks.parent_task_id`) обнаруживаются алгоритмом Тарьяна. В фазе 1 транзакции циклические связи обнуляются (`UPDATE ... SET fk = NULL`), после чего выполняется беспрепятственный каскад.
- **Предкоммитная верификация `PRAGMA foreign_key_check`**: перед фиксацией транзакции движок выполняет проверку на уровне ядра СУБД. В случае малейшей аномалии происходит мгновенный `ROLLBACK`.

### 2. Логическая целостность (Logical & Domain Invariants)
- **Pre-Flight Impact Analyzer (Dry-Run Simulator)**: перед любым удалением строится граф воздействия — точное число затронутых строк по всем 10 таблицам, глубина дерева и проверка бизнес-инвариантов.
- **Financial Compliance Lock**: инвойсы в статусе `PAID` или `LOCKED_AUDIT` защищены бизнес-правилом. Каскад прерывается с детальным отчетом, пока оператор явно не авторизует оверрайд.
- **Синхронизация Soft-Delete**: при мягком удалении флаги `is_deleted = 1` и `deleted_at` рекурсивно прорастают по всему дереву (исключена ситуация, когда дочерняя запись активна у удаленного родителя).
- **Snapshot Archival**: при политике `ARCHIVE_AND_HARD_DELETE` снимок всего удаляемого поддерева сериализуется в `cascade_audit_ledger`, позволяя в любой момент восстановить данные в прямом топологическом порядке.
- **Integrity Doctor & Chaos Lab**: непрерывный аудит физических страниц (`PRAGMA integrity_check`), ссылок и полиморфных вложений с кнопкой инъекции сбоев для проверки обнаружения и авто-лечения базы.

## 📊 Доменная модель (10 таблиц с циклическими и полиморфными связями)

```
organizations (Холдинговые структуры)
 └── departments (Подразделения и отделы)
      ├── employees (Сотрудники и менеджеры; manager_id -> employees.id)
      │    ├── project_assignments (M2M связи)
      │    └── work_logs (Журнал трудозатрат)
      └── projects (Проекты и инициативы; lead_id -> employees.id)
           ├── project_assignments (M2M связи)
           ├── tasks (Иерархические подзадачи; parent_task_id -> tasks.id)
           │    └── work_logs (Журнал трудозатрат)
           ├── invoices (Инвойсы: DRAFT, PAID, LOCKED_AUDIT)
           │    └── payments (Проведенные транзакции)
           └── audit_attachments (Полиморфные вложения)
```

## 🚀 Быстрый запуск

### 1. Запуск веб-приложения (API + Frontend UI)
```powershell
cd C:\Users\Anxiety\.gemini\antigravity\scratch\cascade-guard\backend
python cli.py serve --port 8000
```
*Сервер запустится на `http://localhost:8000` и автоматически откроет интерфейс в браузере!*

### 2. Запуск через CLI (терминал)
```powershell
cd C:\Users\Anxiety\.gemini\antigravity\scratch\cascade-guard\backend

# 1. Список таблиц, активных строк и внешних ключей:
python cli.py tables

# 2. Сухой прогон (Dry-Run) каскадного удаления:
python cli.py simulate departments 1

# 3. Выполнить безопасное каскадное удаление (Архивация + Удаление):
python cli.py cascade tasks 1 --policy ARCHIVE_AND_HARD_DELETE

# 4. Проверить целостность базы данных:
python cli.py audit

# 5. Восстановить удаленное поддерево в 1 клик по ID в журнале:
python cli.py restore 1

# 6. Сбросить и наполнить чистыми демо-данными:
python cli.py seed
```

### 3. Запуск автоматических тестов

```powershell
cd C:\Users\Anxiety\.gemini\antigravity\scratch\cascade-guard\backend
python -m unittest tests/test_cascade_integrity.py
```
*Все 7 тестов физической и логической целостности выполняются за ~0.03 секунды!*
